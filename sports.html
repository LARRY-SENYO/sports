Cryptographic Architecture: Salt & Pepper Demonstration Lab

Interactive cryptographic sandbox demonstrating how Salt prevents rainbow tables and Pepper defends against leaked databases.

1. The Salt (Per-User Public Nonce)

What is Salt?

A random cryptographic string generated uniquely for each individual user during account registration and stored in their database record.

Defeats: Rainbow tables & cross-user pattern analysis. Two users with identical passwords yield completely distinct hashes because their salts differ!
2. The Pepper (System-Wide Secret)

What is Pepper?

A high-entropy secret string maintained strictly outside the database in secure server environment variables.

Defeats: Offline GPU dictionary attacks if the database is leaked. Even if an attacker steals the entire database and salts, they cannot crack hashes without the Pepper!
3. The Secure Formula

Cryptographic Synthesis

The system combines all three inputs in a fixed sequence and calculates the SHA-256 digest:

Final_Hash = SHA256( Salt + Password + Pepper )
